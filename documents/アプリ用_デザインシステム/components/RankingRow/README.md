# RankingRow

コース別・週間ランキングの1行。`gd-card`（内側の余白0）の中に縦に積む。

- 消費側が渡すもの：`rank`、`name`、`exp`（今週の獲得EXP）、任意で `level`、`isMe`。
- 1〜3位は紋章の色で示す：1位 `gold`、2位 `silver`、3位 `bronze`。自分の行は `gold-soft` の地と「あなた」。
- 週間EXPは `gold-ink` の `numeral` 書体。累計レベルは補足に留め、順位の根拠にしない（新規と古参の差を広げないため）。
- 毎週月曜0時にリセット。過去週の履歴でも同じ行を使う。
