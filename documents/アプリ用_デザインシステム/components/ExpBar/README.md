# ExpBar

レベル紋章と次のレベルまでのEXPを示すバー。ホーム画面の最上段（表示優先度1）に置く。

- 消費側が渡すもの：`level`、`exp`（現レベル内の獲得量）、`next`（現レベルの必要量）、任意で `gain`（直前に得たEXP、結果画面で表示）または `title`（「次のレベルまで 160」など）。
- 紋章は `gold-soft` の地に `gold` の輪、数字は `gold-ink` の `numeral` 書体。バーは `parchment-sunk` のトラックに `gold` の塗り。
- EXPは減らない仕様なので、バーが戻る演出や赤系の色は使わない。レベルアップ時はバーを満たしてから次のレベルの0に戻す。
- `gold` の塗りの上に文字を載せない。
