# GuildBadge

学習成果のバッジ。プロフィール画面に獲得日つきで並べる。

- 消費側が渡すもの：`category`（`mastery` 習得 / `coverage` 網羅 / `explain` 説明 / `streak` 継続 / `review` 復習）、`title`、`tier`（`bronze` / `silver` / `gold`）、`date`、`locked`。
- 紋章はカテゴリの漢字1文字（習・網・説・継・復）を明朝で、二重の輪で囲む。段階は金属の色：10問・7日などの1段目 `bronze`、2段目 `silver`、最上位 `gold`。
- 未獲得は `line-strong` の破線で、条件が見えるように名前は出す。
- 絵文字やイラストのアイコンは使わない。
