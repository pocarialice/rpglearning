# PartnerBubble

AIパートナーの発言。ホームの「ひとこと」、採点コメント、解説、採点中の待機演出に使う。

- 消費側が渡すもの：`name`、`persona`（`encourage` 励まし型 / `logic` 論理型 / `rival` ライバル型）、`children`（発言）、任意で `sigil`（紋章の1文字。省略時は名前の頭文字）、`thinking`。
- 吹き出しは `teal-soft`、名札は `teal`。紋章の色で性格を示す：励まし型 `gold-ink`、論理型 `teal`、ライバル型 `crimson`。顔やイラストは描かず、紋章の1文字で表す。
- `thinking` で3つの点が弾む待機演出（最大30秒の採点中）。`prefers-reduced-motion` では止まる。
- 発言は2〜3文まで。口調は選ばれた性格に合わせ、説教や減点の言い方はしない。
- 例のキャラクター名（ミナ、セージ、レン）は仮置き。正式な設定は基本設計で決める。
