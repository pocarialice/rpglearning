# ScoreMeter

キーワード説明の採点結果（100点満点）を合格ラインつきで示すメーター。結果・フィードバック画面で `gd-card` の中に置く。

- 消費側が渡すもの：`score`、任意で `pass`（既定60）、`children`（不足していた観点の一文）。
- 合格は `correct` の塗りと「○ 合格」。未達は `gold` の塗りと「あと15点」。不合格を赤や橙で示さない（責めない仕様）。
- 点数は `numeral` 書体。合格ラインは `ink` の目盛りと「合格 60」のラベル。
- 模範説明はこの下に `PartnerBubble` で続ける。
