RPG学習アプリのデザインシステム。学習者はギルドに登録した冒険者で、資格の問題は掲示板に貼られた依頼、AIパートナーは旅の仲間。羊皮紙と封蝋の落ち着いた世界観で、長い問題文を毎日読んでも疲れないことを最優先にする。

## 世界観と原則

- **読みやすさが世界観より先。** 問題文と解説は必ず `question` / `body`（BIZ UDPゴシック）で組む。明朝は見出しと数字だけ。
- **責めない。** 不正解でもEXPは減らず、ペナルティも無い仕様。未達成や不合格に赤系の警告色を使わない。不正解の印は `wrong`（橙）と「×」まで。
- **報酬は金、行動は封蝋、仲間は青緑。**`gold` はEXP・レベル・報酬、`crimson` は主要アクションと達成の印、`teal` はAIパートナーと案内。この3色の役割を混ぜない。
- **紙の質感は線で出す。** カードは `line` の二重線（依頼書の枠）と浅い `shadow-card`。グラデーション、テクスチャ画像、強い影は使わない。

## 言葉づかい

- 画面の文言は「です・ます」を使わない短い言い切りか体言止め：「本日の依頼」「冒険に出る」「報酬 30 EXP」「あと15点」。
- ボタンは動詞で終える：「冒険に出る」「答える」「採点してもらう」。「OK」「はい」だけにしない。
- RPG用語は意味が通るものだけ：依頼（＝デイリークエスト）、報酬、習得、レベル、紋章。魔法や戦闘の比喩は使わない。
- AIパートナーの発言だけは各キャラクターの口調で話す（例：励まし型「昨日より3問多く解けてるよ」、論理型「説明問題から始めるのが効率的です」）。2〜3文まで。
- 正誤や合否は色だけで伝えず、必ず「○ 正解」「× 不正解」「○ 合格」の記号と文字を添える。
- 絵文字はUIに使わない。

## 色

- 地は `parchment`、カードや選択肢は `parchment-raised`、バーのトラックや入力欄は `parchment-sunk`。
- 文字は `ink`、補足は `ink-muted`。どちらも全テーマの parchment 系の上で4.5:1以上。
- 主要アクションは `crimson` の塗りに `on-crimson`。1画面に1つ。
- EXPバーやレベル紋章の輪は `gold`。`gold` の塗りの上に文字は載せない。金色の文字は `gold-ink`、淡い面は `gold-soft`。
- AIパートナーの吹き出しは `teal-soft`、名札とリンクは `teal`。
- 正解は `correct`（青）、不正解は `wrong`（橙）。赤緑ではなく青橙にして、色覚の違いでも見分けやすくする。それぞれ `-soft` の地を持つ。
- バッジと上位3位は `gold` / `silver` / `bronze`。
- ダークテーマ「夜の酒場」は同じ役割のまま、色を明るく振り直している。テーマごとに値を書き換えず、必ずトークン名で指定する。

## 文字

- 見出し（明朝 Shippori Mincho）：画面タイトル `display`、セクション見出しとクエスト名 `title`、レベル・点数・順位の数字 `numeral`。
- 本文（BIZ UDPゴシック）：問題文 `question`（17px／行間30px）、選択肢・解説・一般本文 `body`、ボタンとラベル `label`、補足 `meta`、最小文字 `caption`（12px、目盛りや日付だけ）。
- フォントはGoogle Fontsから読み込む（`components/bundle.css` の先頭で読み込み済み）。

## 余白・角丸・影

- スマホ画面の左右とカードの内側は `space-4`。選択肢どうしは `space-3`、セクションどうしは `space-6`。
- 角丸は控えめ：ボタン・選択肢・カードは `radius-md`、小さな印は `radius-sm`。バーと紋章だけ `radius-pill`。
- 影はカードの `shadow-card` と押下中の `shadow-press` の2つだけ。

## 状態と動き

- フォーカスは `teal` の3px実線リング（すべての parchment 面で3:1以上）。
- 押下中は `shadow-press` で封蝋を押したように沈む。
- 動きは採点待ちの点の弾み（`PartnerBubble` の `thinking`）だけ。`prefers-reduced-motion` では止める。レベルアップ演出を足すときも1秒以内にする。

## 紋章と記号（アイコン）

- アイコンセットは持たない。意味は漢字1文字の紋章と記号で表す：バッジは 習・網・説・継・復、AIパートナーは名前の頭文字、正誤は ○ ×。
- 顔、マスコット、武器などのイラストは描かない。ロゴは未制定のため、名前は明朝の文字で組む。

## 画面ごとの組み立て

- ホーム（S-02）：上から `ExpBar` → `PartnerBubble`（ひとこと）→ `QuestCard` ×3 → 今日の復習数と `Button`（primary、block）。要件定義の表示優先度どおり。
- 演習（S-04）：`question` の問題文 → `ChoiceOption` ×4 → `Button`（答える）。判定後は `PartnerBubble` で解説。
- キーワード説明（S-05）→ 結果（S-06）：採点中は `PartnerBubble` の `thinking`、結果は `gd-card` の中に `ScoreMeter`、続けて模範説明を `PartnerBubble` で。復習段階は `ReviewStage` を択一・説明の2行で。
- 週間ランキング（S-07）：`RankingRow` を `gd-card` に積む。
- プロフィール（S-08）：`ExpBar` と `GuildBadge` の一覧。
